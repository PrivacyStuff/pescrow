# pescrow

This repository is the pescrow program, a two-sided private escrow on Solana. The crate is `pescrow/`. Program notes are in `pescrow/README.md`. The TypeScript client in `pescrow/sdk` is the program interface.

```bash
cargo test --manifest-path pescrow/Cargo.toml
```

The website is [PrivacyStuff/website](https://github.com/PrivacyStuff/website). https://privacy-stuff.vercel.app is the production site.

The last commit in this repo that still contains the website and the `pproll` program is `5d8f60091ec8534f508f51d3dd8546112b07f7e5`.
